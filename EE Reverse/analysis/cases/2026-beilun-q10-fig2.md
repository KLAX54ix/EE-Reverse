# 北仑卷 题10 图2 — 抛物线（约束式构造）

- **图型**：`function-graph`（抛物线部分图象）
- **来源**：`analysis/beilun-q10-constraints.md`（题干 dump + 截图核对）
- **约束**（从题干抽取，绝不用像素反推）：
  1. 抛物线过原点 O(0,0)；
  2. 最高点 N(n, 6√3)，即顶点纵坐标 = 6√3 ≈ 10.3923；
  3. 过 I(1.5, y1)、J(5.5, y2)，选项 D「y1=y2」⇒ 两点等高 ⇒ 对称轴 x=(1.5+5.5)/2=3.5
     ⇒ n=3.5；
  4. ⇒ `y = A·x·(7−x)`，由顶点 6√3 = A·3.5² ⇒ A = 6√3/12.25 ≈ 0.8483；
     另一交点 x=7；定义域取图上可见部分 x∈[0,5.5]（图2 是"部分图象"）。
- **自由参数**（题面未规定，从原图量）：尺度 U=760 canvas 单位/数学单位；
  原点 O=(7000,21000)；x 与 y **必须同尺度**（否则曲线不是抛物线）。
- **推导**：从 O、N、交点 (7,0) 三个数学点直接生成采样点；不用像素拟合。
- **数值自检**：
  - 顶点高度 = 6√3（与 x 轴同尺度）；
  - I/J 等高（对称轴 3.5）；
  - 交点 x=7；
  - 采样折线相对真抛物线最大偏差 2.07 canvas 单位 = 0.005 mm（56 点）。
- **最终 spec**：`analysis/bl-q10-fig2-constrained.json`（含 curve_points / 轴线 / 标注）
- **落笔**：`ee_draw_figure`（`curves` 或 points 折线）+ 轴用直线 + V 箭头手画。
- **验证**：数值自检通过；用户目视验收（待补 `ee_audit_canvas` 输出）。
- **负案例（踩过的坑）**：
  - 错法：按原图像素拟合抛物线（`row=0.031788col²−41.49col+13588.5`，顶点 row 50.19）→
    顶点高度 ≈ 2.0，而题干要求 6√3 ≈ 10.39；标注还写成 `N(a,b,√3)`。
  - 根因：**抛物线的"高度"是题干给定的数学量，不是栅格像素的纵横比**；栅格非等比缩放。
  - 以后怎么拦：把"顶点高度 = 6√3"写进 `check_spec` 的 `distance`/`point_eq` 检查；
    `curve_points` 生成后用采样点回代 `y = A x(7−x)`，残差必须 <0.01 单位。
