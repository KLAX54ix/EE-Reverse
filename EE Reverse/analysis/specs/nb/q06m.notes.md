## 1. 题干约束（全部进入推导）

1. AB 是半圆 O 的直径 → O 是 AB 中点，半径 R=AB/2，半圆在 AB 上方；
2. C 在半圆上 → |OC|=R；
3. 延长 BC 至 D，使 BC=CD → D = 2C − B（C 是 BD 中点）；
4. CE 是过 C 的切线 → CE ⟂ OC；
5. E = CE ∩ AD；
6. F = BE ∩ 圆（B 之外的第二个交点）；
7. G = 直线 AF ∩ 直线 CE（"延长 AF"）；
8. **BE = AG**（强约束）。

## 2. 自由参数

题面没有给任何长度/角度：整个图形只差一个**相似变换**。原图确定朝向（AB 水平、半圆在上），
所以取 **A=(−1,0), B=(1,0), O=(0,0), R=1**，此外**没有任何量取自原图**——
C 的位置由约束 8 **解出来**（不是量出来的）。

## 3. 推导（脚本里用数值构造 + 二分，闭式仅作交叉验证）

设 C=(c,s)，c=cosθ，s=sinθ>0。则

- D = 2C − B = (2c−1, 2s)；
- AD = D−A = (2c,2s) = 2C ∥ OC ⟹ **CE ⟂ AD 恒成立**；
- 切向 t=(−s,c)，E = AD ∩ CE = C + s·t = (c+c²−1, s(1+c))；`|CE| = s`；
- F：由 |B+λ(E−B)|²=1 解得 λ = −2·B·(E−B)/|E−B|²；
- G = AF ∩ CE。

|BE| = √(5−2c−3c²) = √((1−c)(5+3c))
|AG| = ½·√((1+c)(5+3c))

令 `|BE|=|AG|`（两边为正，可直接平方）：`(1−c)(5+3c) = ¼(1+c)(5+3c)`，
因 5+3c>0，得 `1−c = (1+c)/4` ⟹ **c = 3/5, s = 4/5, θ = arccos(0.6) ≈ 53.1301023542°**。

脚本用 `f(c)=|BE|−|AG|` 在 (0.01,0.99) 上二分 200 次（f 严格单调）求根，得
c=0.600000000000000，与闭式 3/5 在 1e-12 内一致。

精确坐标（全部由 c=3/5 推出，脚本输出）：

| B | (1, 0) |

关键量：AB=AD=2；BC=CD=2√5/5≈0.894427；CE=4/5；CG=2/5；AE=8/5；DE=2/5；
BE=AG=2√17/5≈1.6492422502。

**恒等式/残差**（脚本断言 + check_spec）：
BC=CD（残差 0）；CE⊥OC=90.000000000°；CE⊥AD=90.000000000°；E 在 AD 上（t=0.8）；
F 在圆上（|OF|−1=0）；G 在 CE 上（t=0.5）；A,F,G 共线（残差 1.1e-15）；F 在 A、G 之间（t=0.9412）；
**|BE|−|AG| = −4.4e-16**；AE/DE=4.000000000000；CG=CE/2；AD=AB。

## 4. 四个选项的结论（重要，供 Lead 校对答案）

- **A. AD=AB**：恒成立（|AD|=|2C|=2R=AB），无需 BE=AG；
- **B. CE⊥AD**：恒成立（AD ∥ OC，CE⊥OC）；
- **C. AE=4DE**：AE/DE=(1+c)/(1−c)，只有 c=3/5 时才等于 4 ⟹ **正是 BE=AG 强约束的等价结果，成立**；
- **D. G 为 CE 中点**：恒成立（可算出 G = C + (s/2)·t，与 c 无关）。
