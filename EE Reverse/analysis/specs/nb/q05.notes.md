## 1. 题干约束

1. 四张**正方形**纸片，边长**两两不同**；
2. 放入矩形 ABCD，**相邻纸片之间互不重叠也无缝隙** → 四张正方形 + 两块阴影**恰好铺满**
   矩形（面积恒等式、每条内部边两侧都紧贴）；
3. 阴影在**右上角**与**左下角**；周长之差 `l`（已知）；
4. 问：由 `l` 能确定周长的正方形标号。

## 2. 图形拓扑（从原图量取 + 判定）

原图是轴对齐的，用墨迹行/列投影读出精确像素边界（y 向下）：

| 边 | 像素 | 说明 |
|---|---|---|
| 矩形 | x 6..133, y 14..107 | W=127, H=93 |
| 竖分隔线 | x=79 | 左列 ①／右列 ②③ |
| 横线 | y=87, y=53, y=20 | ①底、②顶(=③底)、③顶 |
| 短竖线 | x=112 (y20..53), x=59 (y87..107) | ③右边、④左边 |
| 灰色填充 | y15..19 x80..132；y20..52 x113..132；y88..106 x7..58 | 右上 L 形 + 左下矩形 |

换成模型坐标（y 向上、原点 B、1 模型单位 = 1 打印像素）：

```
W = a + b = 127     a=①=73   b=②=54
H = a + d = 93      c=③=33   d=④=20
H = b + c + e = 93  e = 6     （右上阴影的水平条带高度）
```

**闭合是精确的**：
- 面积：73²+54²+33²+20² + (54·6+21·33) + 53·20 = 9734+1017+1060 = **11811 = 127·93** ✓
- 边长 73/54/33/20 互不相同 ✓（满足题干"边长各不相同"）
- 每条内部线两侧都紧贴：①|②、①|③、①|④、②|③、②|④；其余空隙正好是两块阴影 ✓
  （`check_spec` 的 collinear / on_segment / equal / angle 检查全部覆盖）

这是原图自带的整数解；题目本身**不要求**唯一解（边长是自由的，只受 W=a+b、H=a+d、
H=b+c+e 与"阴影形状如题"约束），所以量取原图的比例正是"题面未规定的自由量"。

## 3. 题目所问：l 能确定谁

- 右上阴影（L 形）周长：`b + (H−b) + (b−c) + c + c + e = 2H`（telescoping）
  - 数值：54+39+21+33+33+6 = **186 = 2·93**
- 左下阴影（矩形 53×20）周长：**2(a−d)+2d = 2a = 146**
- 所以 `l = 2H − 2a = 2(H−a) = 2d`
  - 数值：l = 186 − 146 = **40 = 2·20**，而 `4d = 2l`
- **结论：④ 的周长 = 2l，不用测量即可知道 → 答案 D（④）**
