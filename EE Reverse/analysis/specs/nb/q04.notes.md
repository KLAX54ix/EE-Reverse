## 2. 约束提取

1. O 是圆心，半径 = 1；
2. A、O、B 共线且 O 是 AB 中点（AB 为直径 ⇒ 半圆），A、B 在圆上；
3. C 在圆弧上，∠AOC = 45°（⇒ C 在 135° 方向）；
4. D 在弧 BC 上（⇒ OD = 1，0° < ∠BOD < 135°，题面未给具体位置）；
5. 四边形 AODC：顶点 A→O→D→C，边 AO（落在直径 AB 上）、OD、DC、CA。

**自由参数只有一个**：D 在弧 BC 上的位置（取原图位置 θ_D = 69.0°）。
其余全部由约束推导，脚本里没有手填坐标。

## 3. 构造（model 坐标，y 向上，O 为原点）

```
A = (cos180°, sin180°) = (-1, 0)
B = (cos0°,   sin0°)   = ( 1, 0)
C = (cos135°, sin135°) = (-√2/2, √2/2)
D = (cos69°,  sin69°)  = (0.35837, 0.93358)     ← 唯一自由参数
圆弧：圆心 O、半径 1，a0 = 180° → a1 = 0°（经 90° 过顶，采样 128 段折线）
线段：A–B（直径）、O–C、O–D、C–D、C–A
标注：A、B、C、D、O（偏移量见下）
```

标注偏移（model 单位，图形尺度 = 2；为尺度 6~8%）：A(−0.10,−0.09)、
B(0.09,−0.10)、O(0,−0.13)、C(−0.11,0.10)、D(0.04,0.15)——均放在顶点外侧、
不与任何线段/圆弧相交（预览图逐项核对过）。

## 5. 假设与不确定点

1. **题面缺字按原图补**：原图 A、B 都在基线上、O 在基线中点且 OA、OC、OD 都是半径，
   所以弧是"以 AB 为直径的半圆"，题中缺字应为"AB 是半径为 1 的半圆弧"（抽字残句
   "BC是半径为1的圆弧" 无法成立——若弧为 BC，B 就不会在直径端点上，且与 ∠AOC 冲突）。
2. **D 的位置**：题面说"动点"，故只按原图取一个位置（θ_D = 69.0°，测量范围
   68.5°～69.8°，低分辨率位图误差 ±0.7°）。取 69.0° 与原图肉眼一致；若 Lead 想
   微调，改 `tools/nb_q04.py` 的 `THETA_D` 后重跑即可。
3. **不复刻答案图辅助线**：`fig07.png` 是答案图（多 CF⊥AB、OE⊥CD、F、E），题图
   `fig06.png` 没有，故不画。
4. **无粗点**：原图各交点没有加粗实心点（`fig06.png` 像素检查：O、C 附近只是线交叉，
   无点状团块），故 `dots` 为空。若 EE 里需要点出顶点，可把 O 或全部顶点加进 `dots`。
